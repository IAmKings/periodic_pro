周期表 Pro · 图标使用规范

B / 元素 P · 2026.11.03

v1.0

P 的一角，成为独立的元素方块。P 关联 Periodic、Pro 与磷元素；方块及间隙共同构成标识，不可拆改。

01 / 品牌色

品牌紫 #6650A4
RGB 102 / 80 / 164 · CMYK 38 / 51 / 0 / 36
白 #FFFFFF
RGB 255 / 255 / 255 · CMYK 0 / 0 / 0 / 0

紫白对比约 6.46:1。CMYK 为近似换算；Pantone 未指定，印刷需打样。

02 / 留白与尺寸

  • 单位 u 为主笔画宽度，母版 u = 32。
  • 独立标识外部留白至少 1u。
  • 符号最低 16px；≤32px 用 small 版本。
  • 横式组合 ≥160px 宽，竖式 ≥128px 宽；更小仅用符号。

03 / 背景与版本

白底用紫色或黑色；深底用反白。反白笔画减细 1 单位，改善光学重量。图片背景先增加纯色承载面。

04 / Android

  • 108dp 满画布分层；前景位于中心 66dp 直径安全圆内。
  • 普通图标浅深色统一紫底白标。
  • monochrome 只包含形状，颜色交给系统。
  • Android 7.x 使用独立矢量回退；Android 8+ 使用 adaptive-icon。
  • 商店图：512×512、sRGB、直角满底、无外部阴影。

05 / 字标与禁用

Noto Sans CJK SC Medium（SIL OFL 1.1）；交付字形已转曲，不依赖安装字体。

  • 勿拉伸、旋转或按包围盒重新居中。
  • 勿填掉间隙、移动独立方块。
  • 勿添加数字、描边、渐变、发光。
  • 圆角预览不可代替直角商店原稿。
